# Plan artifacts

- Canonical format: Markdown.
- Location: `docs/plans/`.
- Names: lowercase kebab-case.
- Assets: `docs/plans/assets/<plan-name>/`.
- Plans include purpose, problem, solution, relevant files, ordered phases, checklists, tests, validation commands, references, metadata, and amendments.
- Status: `[ ]` idle, `[~]` in progress, `[x]` complete, `[!]` failed or blocked.
- Preserve completed history; record changes in amendments.
